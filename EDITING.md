# Editing this portfolio

This is a static HTML/CSS website, with no build step or dependencies.

## Preview

Open index.html in a browser. To serve it locally, run `python -m http.server 8000` in this folder and open the address it prints.

## Update content

- Edit index.html for the introduction, skills, project cards, experience and contact links.
- Edit retail.html, banking.html, sales.html and chocolate.html for the four studies.
- Replace the portrait and dashboard PNGs while keeping filenames, or update the matching HTML paths.
- Replace 13-Omar_Hamdy_Data_Analysis_CV.pdf to update the CV.
- Edit style.css for colors, spacing and responsive layout.

After changes, test phone and desktop sizes, navigation links, screenshot links and CV download.

## Add project source files later

Review workbooks or PBIX files for personal information, confidential records, external connections, hidden sheets, author metadata and data-sharing rights before uploading. Add only documented tools, data sources, steps and findings. Do not describe training data as client or employer results.
